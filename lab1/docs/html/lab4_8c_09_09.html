◆ main()

int main ( )

Точка входа в программу.

Запрашивает у пользователя количество строк и столбцов, создаёт динамическую матрицу, заполняет её значениями и демонстрирует различные варианты её вывода.

Returns
0 При успешном завершении программы.

Матрица выводится три раза: с параметрами по умолчанию, с пользовательским заголовком и без рамки. После завершения работы выделенная память освобождается с помощью функции freeMatrix().

Выводит матрицу на экран.
