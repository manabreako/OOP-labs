int process (\begin{DoxyParamCaption}\item[{int \texorpdfstring{$\ast$}{*}\&}]{arr}{, }\item[{int}]{size}{}\end{DoxyParamCaption})}



Обрабатывает динамический массив и удаляет все элементы, начиная с первого отрицательного элемента. 

Функция ищет первый отрицательный элемент в массиве. Если отрицательный элемент найден, создаётся новый динамический массив, содержащий только элементы до него. Старая память освобождается, а указатель arr получает адрес нового массива.


\begin{DoxyParams}{Parameters}
{\em arr} & Ссылка на указатель динамического массива. \\
\hline
{\em size} & Размер исходного массива. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Новый размер массива. Если отрицательных элементов нет, возвращается исходный размер.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
После выполнения функции указатель arr указывает на новый массив, если в исходном массиве был найден отрицательный элемент. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Переданный массив должен быть выделен с помощью new\+[]. 
\end{DoxyWarning}
